# BlogSpace ✍️

A simple and user-friendly blog platform built with Flask and SQLite.

## Features

- User Registration
- User Login and Logout
- Create Blog Posts
- Edit Your Own Posts
- Delete Your Own Posts
- Add Comments
- View All Blog Posts
- Password Hashing
- Simple and Responsive UI
- REST API for Blog Posts

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Werkzeug
